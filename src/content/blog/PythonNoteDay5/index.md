[[Python一月预习]]
一.函数基础语法
	0.函数的类型：函数不用定义类型，本质是因为动态类型/鸭子类型
		动态类型：参数/返回值本身没有“类型”，只是“标签”；
		鸭子类型：调用指向的对象本身，看其是否支持对应的操作
			补：类型标注： -><数据类型>
	1.函数的定义：
		`def(define) <函数名>(形式参数1，形式参数2......):
		    `代码块
		    `return 返回值
	2.形式参数与实际参数：
		形式参数是在定义函数时（）中写的参数名（“占位”）
		实际参数：在调用函数时传入的值
		注意：==形式参数和实际参数的类型应该相同！！==--e.g.字符串对应字符串“”
	3.函数的返回值：
		语法：`return 返回值
		没有return值，则返回none（真值性为假）
			返回多个值`return a,b`：直接返回元组
		注意：返回值可以是任何数据类型；return后函数直接结束（“break”）
	4.“函数是对象”的理解与函数的CPython本质：函数与函数体分离
		（1）函数在CPython底层也是一个C结构体--一个`pyfunctionobject`对象，对象本身与其他对象相同，都有ID、type，中有字段保存函数的内容，还有真正指向代码块的==**指针**==
		（2）函数体\代码对象是“干货”，其中有全部字节码；函数对象是“壳”，保存的是“上下文”
		（3）调用过程：先分派一个槽，是函数成为对象；后建立一个“栈帧”，建立函数体的工作环境；后执行函数体字节码；最后返回+销毁
		（4）是对象，使函数可以赋值变量、可以作为参数传、可以作为返回值、可以进入容器
			闭包、装饰器、高阶函数、回调这些特性存在的基础就是“对象”
二.函数的参数：
	0.注意传入的参数应符合格式：字符串要加双引号“”
	1.位置参数：固定位置的参数/形式参数的顺序也是参数的一部分/“有位置”的参数
	（e.g.按一定顺序输出的序列）
	2.关键字参数：解决当位置参数多的时候参数不好管理的问题
	可以在声明函数时直接将对应的形式参数赋值；顺序可以和后续输出顺序不同
	但是更多时候是在调用函数的时候直接 `<参数名>=值`传值
		位置参数一定在关键字参数之前
	3.默认参数：在参数定义时指定默认值---如果没有参数输入，则使用默认函数；否则覆盖
			默认参数应放在最后；默认参数和关键字参数的应用范围不同（定义/调用）
		参数中的"/"：左侧必须传递位置参数，不能使用关键字参数；右侧无要求
		参数中的"* "：左侧无要求，右侧必须使用关键字参数
			语法：`def <函数名> (参数1，参数2，/，参数3)`--单独占一个位置 
	4.收集参数：可以接受传入参数值数量不定的形式参数
		语法：* <参数名>（==区分前“位置参数--用逗号占位”==）  
		实现原理：使用元组进行打包--序列，具有序列的性质与方法
		收集参数和其他形参在一起：使用关键字参数传值
		反向利用：元组在传递参数时的解包：* 
			语法：函数名（* <元组名>）--元素数量和参数数量应相同
三.作用域：
	0.定义：变量可以被访问的范围，由变量被赋值的位置决定
	1.局部作用域：在函数中定义的变量（局部变量）的作用域
		在函数中定义，就只能在函数中被访问
	2.全局作用域/全局变量：在函数外部定义的变量，位置是全局
		全局变量可以在函数内部被访问
		在函数中，局部变量会覆盖全局变量；在函数外，则回归全局变量
			局部和全局变量的ID不同
			在函数中对全局变量赋值本质是创建一个同名的局部变量覆盖
	3.global语句：在函数内部突破局部作用域（不推荐）--直接在全局作用域读写，进字典
		语法：`global <变量名>`，之后再赋值则突破局部作用域
	4.嵌套函数：函数中包含函数
		访问性：嵌套的内部函数无法在全局（函数外）直接调用，但是调用外层则会调内层
		作用域：内层函数的作用域小于外层（层层包裹）
	5.nonlocal语句：在内部函数修改外部函数的变量--只在嵌套函数中有用，写入外层函数的cell
	6.LEGB规则：Local-Enclosed-Global-Build-In
		是作用域优先级：从高到低（覆盖顺序），局部-外层-全局-内置（内置函数名）
			注意：不要起和内置函数名字相同的变量名
	7.作用域的意义：从内到外，内层变量最灵活，使其不会被外层变量干扰，作用范围明确
	8.作用域的实现：
		在编译时定名、归类（进行语义分析时，用”符号表“翻译成不同的字节码指令），运行时存取
		变量存储位置不同--作用域不同：局部变量存储在栈帧里--函数运行结束，栈帧销毁，变量就消失；全局变量存在字典里，根据字符串查字典；自由变量(cellver--cell variable)在堆上的cell对象里
			参数本质是局部变量--都存到栈帧上
			cell对象：堆上的”箱子“，存指针（一个，指向一个变量--指向外层函数变量）
				过程：见下文闭包，指针还被内层函数指向-可以被内层函数访问
四.闭包(enclosing)：--==**直接修改内层函数参数**==
	0.直接在全局调用函数的内层函数：
		在外层函数中将内层函数作为返回值返回--这样调用外层函数本质是引用内层函数
			语法：函数内部： return <函数名> 不用加括号
				  函数外部直接访问：<外层函数名>( )( )
				  等效于：<变量名> = <函数名>( ),<变量名>( )
		注意：将函数返回值赋值给变量后，理论上函数内部变量值是不能传出的，但实际可以，并且变量还会持续存在，因此，==**核心就是可以在函数外部访问（修改）函数内部的变量值的功能**==
	1.利用（核心性质）：
		（1）”工厂函数“：定义一个嵌套函数，将其赋值给变量（变量可是函数--一切皆对象）
		再通过修改变量函数的参数，达到不同的处理效果
			形象理解：”工厂“中的”流水线“；”母函数“与”子函数“，大致处理-细化功能
		（2）是函数有”记忆“：利用可以修改内部变量、持续存在的特性，创造”有记忆“的函数
	2.实现原理：使用”cell“（闭包单元）C对象
		外层函数的作用域可以活下来，是因为有一个C对象叫cell，同时被外层函数和内层函数指向，而因为对象的”存活“性质，cell对象的引用数不为零，所以依然被保留
==**五.装饰器**==：
	0.核心原理：将函数作为参数传递给另外一个函数（有返回值，则传递返回值）
		语法：`def <函数名>(func(什么名字都行，就是一个参数)) 函数内部：func()
		`(传入变量:)<函数名>(<被调用函数名>)`--被调用的函数可以没有返回值（显式调用）
	1.自动执行（隐式调用）--装饰器
		语法：@<被调用函数名>（后加另外一个函数）
		意思：在调用B函数时自动在其中执行A函数（将B函数自动作为A函数的参数传入，A与B共同完成一项功能）（注意A要允许传入--参数和变量（）缺一不可）
		本质：一个普通函数（装饰器是”语法糖“，简写）
	2.多个装饰器同时作用在一个函数上：
		语法：从上到下，@A, @B, @C：从内到外计算（调用）
六.lambda表达式--匿名函数（）
	0.定义：`lanbda <变量名>:<表达式>
	1.语法：<变量名> = lambda 参数（不加括号/可不止一个）：表达式
	2.本质是表达式--可以放在一些语句不能出现的地方（e.g.列表）
	3.因为很紧凑，为保持可读性，其定位是实现简单功能的表达式
	4.本质和函数相同（type是func），返回的是一个函数对象；调用时才返回值
