## 零、综述：
0.类与对象是一种封装代码的方法（为了提高代码的管理、复用效率）
1.对象 = 属性（静态特征） + 方法（动态特征）
    类比真实世界：有静态的固有内容，也有动态的行为
## 一、基本语法：
0.创建对象：
    需要先创造类，再通过类创造对象（简化多次创造相似对象）
        有模具（类），再进行批量生产（对象）
        类的创建：`class <类名>(大写开头)`；属性是类中的变量，方法是类中的函数
    再通过类创建对象：类比函数调用，`<变量名> = <对象名>()`--变量名就是一个实例对象
        这样，对象就获得了类中所有的方法和属性；可以依据一个类中创建无数个对象
    调用类中的方法：`<对象名>.<方法名>()`
    修改类中的变量名：`<对象名>.<属性名> = <值>`
        对象间是相互独立的，修改一个对象不会改变其他对象
    给对象动态创建新的属性：同上，将一个新的属性名赋值
        可以使用`dir(<对象名>)`函数判断对象中的属性
1.封装：
    将特征和行为放在一个“容器”中，即前文在定义类的时候，将属性和方法放在一起
2.self（绑定）：解决一个类中的函数对应多个对象时对象调用之间的“隔离”问题
    关键：通过实例对象访问类中方法的时候，需要将方法与实例绑定--通过参数传入
    类中函数的创建（方法）：`<方法名> (self,value)`
        首个位置参数self是实例对象参数，用于将对象绑定函数；后面value位置参数是函数本身所需位置参数；
        具体内容：`self`传入引用对象，是指向对象的指针，方法通过指针访问对象（快）
        在python中验证：
        `print(c.clean.__func__ is Cleaner.clean)  # True`
        `print(c.clean.__self__ is c)              # True`
        CPython固定将引用对象放到方法参数中的第0个槽位，本质是读槽位上的内容，与变量名无关；self只是约定的名称，提高可读性
    因此，若想通过对象正常访问方法，必须有一个self参数做绑定，并且要显式写出`(self)`
    在写法上，`c.<类名>()`与`<类名>.<函数名>(self)`相同
    绑定是双向的，所以可以通过函数内部的方法给对象赋予新的属性
    语法：`self.<变量名> = <值>`进行参数传出（类比C中指针）--所有对象共享，慎用！！
3.继承：
    子类可以继承父类（基类/超类）的所有功能，并在其基础上扩展功能
    语法：`class<子类>(父类)`，之后操作相同
    在子类中的属性和方法名会覆盖父类的属性和方法名
    判断对象从属的类：使用`isinstance(<对象名>,<类名>)`方法
        子类也会继承依据父类创建的对象
    判断子类：使用`issubclass(<类1> , <类2>)`方法
    多重继承：一个子类继承多个父类
        语法：`class <子子类>(<父类1>，<父类2>)`
        规则：从左到右访问多个父类，如果有同名属性/方法，则以先访问到的为准，即**先左后右**（左侧）；而对左侧没有右侧有的属性/方法则会取右侧的
    阅读类的继承：从实例化对象开始，从上至下
    CPython实现：先略过
4.组合：将多个类型再进行“打包”，放到一个平行的对象中（没有从属关系）
    语法：先定义一个类，在其中：`<变量名> = <类型名>()`，多个对象放到一个里面
    注意类之间没有从属（继承）关系，只是对象之间有引用关系
5.灵活使用类：
    定义一个空类（其中只有pass），可以通过其创建实例对象，再在对象中创建属性，实现字典
    **类和对象在性能上可能没有什么优势，但是其可以切实提高代码的可读性、降低开发难度**
6.构造函数：“个性化定制对象”（术语：initialize，初始化方法）
    语法：在定义类的同时定义构造函数 : `__init__(self,value)`；在构造函数内部，注意一定要`self.<变量名>`
    **对`self.<变量名>`的理解：**
        self是实例对象的引用对象（指针），指向实例对象；
        `self.<变量名>`是在当前这个**实例**对象中，存放或读取一个属性（"."是访问对象操作）
        其真正的价值在于可以在函数中访问实例对象的属性，是其能够长期保存，而非随着函数的销毁而销毁，使其可以持续地被访问，值也会一直保留（类比闭包），因为它是在对象“名下”
    对一个“构造函数类”进行调用，要先对初始函数进行赋值：
        `<变量名> = <类名> (函数值1 ， 函数值2)`
    一种调用类型中的方法：`<变量名>.<方法名>()`（调用未绑定的父类方法）--有问题，会造成钻石继承
7.重写：在子类中继承父类的构造函数，再定义新的变量，进行运算
8.钻石继承：得名于类之间的继承关系连线像钻石（A - B/C - D），调用C的时候，A会被调用2次
    **输出顺序**：注意输出的是调用实例化对象的结果，按照其对应的类中的函数顺序输出
    解决方法：调用`super()`函数，避免出现这样的问题：
        语法：`super().__init__()`，本质是改变D的MRO（方法解析顺序），使最初的A不会执行两次（将钻石形状的“多继承”MRO压缩成线性的，即D-B-C-A），使A不会被重复
        所以，`super()`的作用是从当前实例的MRO中，找到后一个类（此时可以将它理解为那个类的“代词”，`super().<方法名>`就是调用对应类的方法）（顺序上），而非找父类
        `super()`没有参数，但是编辑器会自动关联它所在的类和实例
        拼接的过程：结合每一个类的MRO（B-A,C-A,D-B-C（根据D类括号中的继承顺序决定）），不改变局部顺序，将钻石继承压缩为线性
        查看MRO：`<类名>.mro() 或 <类名>.__mro__`
9.Mixin（“混入”）：一种设计模式（常见的代码解决方案），指在原有类的基础上专门添加一块可复用能力的类，类比“装饰器”。一般在命名过程中会加上后缀`Mixin`
10.多态：同一个运算符/函数/对象 在不同的场景下有不同的效果
    e.g. ：对运算符，乘法符号`*`在数字中表示相乘，在字符串中表示复制再拼接多次
    类继承中的多态：同一个父类衍生出多个子类，子类重写了构造函数和方法，实现不同的功能（类比函数闭包）
    多态对象应用：实例化多态类之后，将实例化对象作为参数传递给函数，函数再依据这一参数执行不同内容
11.私有变量：使对象中的属性和方法无法被外部所访问（C++中的private）
    Python中没有权限系统，通过其他方法限制访问：
        名称改写，使变量在函数外不可以简单地通过原名改写：
        单下划线：`_<变量名>`：只是约定，使外部不可以太简单地访问到
        双下划线：利用编辑器触发名称改写，`__<变量名>`会被编辑器改写成`_<变量名>__`，使其更不容易被通过名称访问
        `__slot__`类属性：限定实例只能有其中属性，避免随意添加新属性，同时减少内存开销
            语法：`__slots__ = ["<变量名1>" , "<变量名2>"......]`
            但是slot只限定了属性，没有限制访问性
            slot的继承：子类会继承父类的slot，但是slot本身不会生效（不会限制添加属性），新的属性会保存在字典中
                解约内存的原理：固定属性，不再使用字典，解约字典存储空间
12.魔法方法：详见Python中的魔法方法
