## 一、核心认知：序列 —— Python 内置数据结构
1. 定义：“序列”是一类共享统一套操作的类型，其中包含字符串（str）、列表（list）、元组（tuple）
2. 序列的特点：有序、可下标、可切片
3. 序列的底层原理（CPython）：对象头 + 元素指针数组
    - 序列对象 = 统一的“头”（引用计数 + 类型指针 ob_type）+ 类型专属的数据区
    - **list 的数据区永远是一个“指针数组”**（C 里是 `PyObject **ob_item`），槽里装的都是指向其他对象的指针，从不直接存值——一维、嵌套都一样
        - 区别只在：指针指向的对象“可变”（list/dict）还是“不可变”（int/str）——不可变时共享无害，可变时才“牵一发而动全身”（浅拷贝的根源）
    - 所以 list 能异构（[1,"hi",[2]]）、能让多名字共享同一元素、也才会出现“浅拷贝只复制外壳、内层仍共享”
    - *对照 C：list 对标的是 C++ 的 std::vector（动态扩容的指针数组），不是 C 的定长数组；共同点只是“连续内存 + 下标 O(1) 访问”*
    - **增删改查的底层复杂度**（呼应“指针数组”的结构）：
        - 查 a[i] / 改 a[i]=x：O(1)——连续内存，直接按下标读写指针（负索引先做 i+len 换算）
        - append(x)：摊还 O(1)——写预留空槽，塞满才 realloc 扩容（“超额分配”，新容量约多预留 1/8）
        - insert(i,x) / pop(i) / remove：O(n)——用 memmove 把后面的指针整体搬移一格
        - 全程搬移的是 8 字节的“指针”，从不移动元素对象本身
4. 序列是“协议”：
    - 什么是协议：一套双方约定好的“契约”，一个共同遵守的规则，规定交互时的格式、顺序、语义，但是不规定双方内部如何实现
    - 协议的性质：只规定行为、不管如何实现；改动内部不影响协议；协议双方可互相替换
    - 协议的PY实现：“鸭子类型”，只查看有没有对应方法（看方法名是否相同），不看其他。
    - CPython的底层实现： `PySequenceMethods` 函数指针表
        - “协议”在源码中是结构体，其中装满了函数指针。每个序列类型指向自己的方法表，方法表再指向一个具体C实现--决定其性质与操作
        - “鸭子类型”：不看len(x)中x的类型，只通过ob_type（所有对象头部的指针）指向对象的具体类型（指向类型对象，其内部有方法表，记录如何处理对应数据）
        - **负索引、切片、in 这些“自带的强大功能”，本质都走这张函数指针表分派到具体 C 实现**：负索引 = i+len 的一行换算；切片 = 建 slice 对象 + 复制指针数组（所以是浅拷贝）；in 会回退到逐元素遍历
5. 三种序列的对比：
    - | 类型 | 示例 | 可变 | 元素类型 | 典型用途 |
    - |---|---|---|---|---|
    - | str | "Python" | 不可变 | 都是字符 | 文本处理、日志 |
    - | list | [1,"a",2.5] | 可变 | 可异构（随便混） | 动态增删元素 |
    - | tuple | (1,2,3) | 不可变 | 可异构 | 坐标、多返回值、字典 key |
6. 序列共有的语法/方法（str、list、tuple 三兄弟通用）：
    - 三种序列共享同一套“序列协议”，所以这些操作对它们都成立（str 的“元素”是单个字符）：
    - ① len(s)——度量长度：返回元素个数
        - 长度存在对象头里，O(1)，不用像 C 那样从头扫（**与 C 数组不同，序列自己“知道”自己多长**）
    - ② x in s / x not in s——成员判断：x 是否在序列里，返回布尔值
        - 底层走 __contains__；list/tuple 逐元素 == 比较（O(n)），str 是子串匹配
    - ③ min(s)/max(s)/sum(s)——极值与求和
        - min/max 返回最小/最大元素（元素要能互相比较）；sum 只对数字序列有效
        - **C 里这些都要手写循环，Python 一条函数搞定**
    - ④ 序列比较：==、!=、<、>、<=、>=
        - 字典序：从左到右逐个元素比，第一个不同的元素定大小；前缀相同时短的小（[1,2] < [1,2,3] 为 True）
            - str 和 list 之间不能比（不同类型直接报错）
    - ⑤ all(s)/any(s)——全真/任一真
        - all 全真才 True；any 任一真就 True；**易错：空序列 all([])=True、any([])=False**
    - ⑥ reversed(s)——反向
        - 返回“反向迭代器”（惰性，不复制、不占内存），要看内容要 list(reversed(s))
        - 与切片 s[::-1] 不同：切片直接造出新序列，reversed 只是迭代器

## 二、列表的语法：
1. 创建列表：中括号[]括起，其中元素用逗号分隔
2. 列表中可以同时存放不同类型的元素
3. 遍历列表：使用for的迭代， for each/i in <列表名>（each/i不用提前定义，直接用即可）
    - **遍历进阶（告别 C 味的 range(len)）**：
    - range：从0到len-1
        - enumerate——边遍历边拿“下标 + 值”：
			```python
			for i, f in enumerate(fruits):      # i 下标，f 值
			for i, f in enumerate(fruits, 1):   # 从 1 开始编号
			```
        - zip——把多个序列“拉链”成对（长度不同取最短）：
			```python
			for name, score in zip(names, scores):
			```
        - *注意：zip 返回迭代器（惰性，遍历一次就耗尽），要反复用先 list(zip(...))*
4. 列表的下标索引：<列表名>[ 下标 ]，**下标从0开始**
    - <列表名>[-1]，索引最后一个元素，倒数第二个是-2......
    - **负索引换算：-k = len - k**（s[-1] = s[len-1] = 最后一个）
5. 列表的切片：从单个索引值变成一个范围
    - 语法：<列表名>[开始的位置:结束的位置]或者为<列表名>[开始:结束:跨度值]
        - 注意：从0开始；前开后闭--开始元素可被取到，结束元素不可取到；**跨度值是每一次的”步长“，即为相邻取的元素的下标差**
        - 三个内容和均可以省略，有[ : : ]，则是默认从头开始，到尾结束（取最后一个）
        - 若跨度值取-1，则为倒序输出
        - **切片 vs 索引的越界**：索引越界报 IndexError（s[100]）；切片越界自动裁剪、静默返回（s[0:100] 返回整个）——切片语义是“尽量取这段”，索引语义是“精确取这一位”
6. 修改列表的方法：
    - 增：<列表名>.append()，在列表末尾增加一个指定元素
        - <列表名>.extend([可迭代对象])，在列表末尾添加一个可迭代对象（含有多个元素的对象）
        - <列表名>[len(<列表名>):] = [可迭代对象]
            - 原理：
                - 切片赋值--对列表的切片进行赋值操作- s[start:stop] = iterable，是将切片范围内的元素换为等号右侧可迭代对象中的元素
                - s[len(s)：]表示从末尾取到末尾，因这样越界了，所以这是个空切片。之后用对象替换这个切片，实际上就插入了新的元素
                - 同理：s[ : 0]=[对象]表示在开头插入元素
        - <列表名>.insert(索引位置，插入元素)，在列表中任意一个位置**插入**元素
            - 据此，可通过在下标索引0处插入元素在开头插入，len(s)处在结尾插入
    - 删：<列表名>.remove("元素名")，删除对应元素
        - 注意：若有多个同名元素，则会删除第一个；如果没有，则会报错
        - **<列表名>.pop（下标），删除指定位置元素**
        - <列表名>.clear（），删除整个数组
    - 改：替换列表中的元素，和访问类似，使用下标索引和赋值，直接替换对应值
        - 单个改变：<列表名>[索引] = 值
        - 多个改变：本质同上，使用切片（不如说利用切片增是改的特殊用法）
            - 原理：先将赋值号左侧的内容删除，再将右侧的片段插入
        - 排序列表：使用.sort()方法正序排列；.reverse()倒序排列
            - **sort 与 sorted 的区别**：L.sort() 是原地排序（改 L，返回 None）；sorted(L) 返回新列表（L 不变）
    - 查：<列表名>.count(元素值/名)，查找元素出现次数
        - <列表名>.index(”元素名“)，查找元素所在下标
            - 据此，在不知道位置的情况下替换元素：
                - <列表名>[<列表名>.index(元素名)] = 替换元素名
        - <列表名>.index(元素名，开始位置，结束位置)，查找在指定区间内的元素下标值
        - .copy：浅拷贝，变化名字+拷贝指针（放在新对象里），内容本身不拷贝
        - D2-对象模型&类型系统--变量与对象，浅拷贝与深拷贝
7. 列表的加法和乘法：
    - 加法：a + b = 将b列表拼接到a列表后
    - 乘法：a * n = 将a列表循环输出n次，组成一个新列表
8. 嵌套列表：列表中的元素为列表--表示矩阵
    - 嵌套列表的访问：
        - 遍历：两个for循环，注意
        - 索引：<列表名> [][]  [] 访问（从0开始）
        - 深拷贝：复制所有内容，包括最底层的元素，到一个新的内存空间中
            - 语法：借助copy模块
                - import copy
                - copy.copy(<列表名>)--是列表模块下的列表函数，不是方法，浅拷贝
                - copy.deepcopy(<列表名>)--深拷贝
            - 深拷贝效率低，普通情况尽量不用
9. 列表推导式：提高可读性和程序运行效率
    - 语法：[表达式 for i in 可迭代对象]（表达式+for循环）
        - 理解：将这个表达式的结果放在这个列表里
    - 同样适用于字符串
    - 原理：直接用for循环是通过迭代一次修改每一个列表中的元素；而推导式为**直接创建一个新列表并赋值到原先的变量名**
    - 列表推导式的嵌套：本质是循环嵌套

    - 同样可以使用.count和.index和

## 四、字符串：
- **字符串的底层（CPython，呼应 D2 的整数缓存）**：
    - str 是不可变 + 可变长类型：对象 = 头 + 元数据 + 字符数据区
        - length 长度字段：所以 len(s) 是 O(1)，不用像 C 那样从头扫到 \0
        - hash 哈希值“惰性缓存”：首次被 dict/set 用到才计算并缓存——字符串当字典 key 高效的原因
    - **“驻留”（interning）**：像 "hi" 这样长得像标识符的字符串字面量，会被 CPython 放进全局驻留池复用
			```python
			a = "hi"; b = "hi"
			print(a is b)                  # True —— 标识符样式，被驻留复用
			x = "".join(["h", "i"])
			print(x is a)                  # False —— 运行时新建，不驻留
			print(x == a)                  # True —— 判断相等永远用 ==
			```
        - 与整数缓存（-5~256）同理：is 是“实现优化导致的陷阱”，**判断相等一律用 ，is 只用于和 None 比或确需比身份**==
1. 同元组，不可变，可哈希--修改后创建新的字符串并重新绑定
2. 字符串格式的调整：
    - 已有一些在D2-对象模型&类型系统中记录
    - .center(宽度)是将字符串放入指定宽度的中心，若宽度小于字符串长度，则不变
    - .ljust(宽度)(left adjust)，是将字符串放到指定宽度的左侧
    - .rjust(宽度)(right adjust)，是将字符串放到指定宽度的右侧
        - 上述三种方法支持填充非空字符，有.<方法名>(宽度，字符)
    - .zfill(宽度)(zerofill)，是将0填充至指定宽度左侧（制表时统一格式）
3. 字符串的查找功能
    - 查找某一字数出现次数：.count(元素名，start，stop)
    - 查找子字符串下标值：
    - .find和.rfind，前者从左往右，后者从右往左，除第一个
        - 语法：find(“子字符串”)，和rfind（“子字符串”）
    - .index和.rindex，同上，查找下标，从左往右与从从右往左，找第一个
        - 不同：若没有对应子字符串，find会返回-1，index会返报错
4. 字符串的格式：空格与tab
    - Python推荐使用空格，而非tab
    - 使用.expandtabs(空格数)将tab替换成指定数量的空格
5. 字符串的修改：
    - .replace([旧字符串]，[新字符串])，将字符串中的子字符串修改
    - .maketrans (“旧字符串”，“新字符串”，“忽略内容（可省略）”)将字符串以一定规则换：
        - .translate(<表格名>)，表格指定转换规则
            - 表格的获取/规定：
            - <表格名> = str.maketrans(旧字符串”，“新字符串”，“忽略内容（可省略）”)
6. 字符串的判断：（返回布尔值）
    - <字符串名>.startswith("子字符串")，判断子字符串是否在原字符串开头
        - 可以加入开始和结尾的参数：startswith("子字符串"，开始下标，结尾下标)
        - 子字符串可以以元组的形式作为参数：只要元组中有一个子字符串成功匹配，则为真
    - <字符串名>.endswith("子字符串")，判断子字符串是否在原字符串结尾
    - .istitle()判断是是否所有单词（空格隔开）的首字母都大写
    - .isupper()判断是否所有字母都是大写
    - .islower()判断是否所有字母都是小写
    - .isalpha()判断是否都是英文字母
    - .isspace()判断是否为空白字符串（空格、制表符、换行符）
    - .isprintable()判断是否都为可打印字符--**转义字符不可打印**
    - 判断数字：
    - 共同判断前提：字符串非空、每一个字符都有“数字”属性（负号、小数点没有数字属性），否则直接返回false--一个个字符判断，不会看整个字符串是不是数字--不能有符号
        - .isdecimal：必须是阿拉伯十进制数字（全角、半角均可）
        - .isdigit：在基础上兼容上标下标
        - .isnumeric：在基础上兼容所有unicode中有数值的字符（汉字、罗马数字等）
    - 判断合法标志符：.isidentifier()
    - 判断保留标志符：使用keyword模块中的keyword函数--先 `import keyword`
7. 截取字符串：见D2-对象模型&类型系统中字符串部分
    - 推广-.l/rstrip(“字符”)--并不是空字符，而是有字符作为参数：
        - 单个字符：从字符串一段开始，依次读取字符串中元素,相同则删除,直到有不同字符
        - 多个字符作为参数：只要和参数中的一个相同，直到遇到第一个在参数外的字符
8. 字符串的拆分和拼接
    - 拆分：.partition()和.rpartition()
        - 操作：以括号中参数为分隔符（“分界线”）进行分割，分成一个三元元组（分隔符占一个，以第一个与参数相同的元素作为分隔符）；partition从左侧检查，rpartition从右侧（parition意为分割）
    - 分割：**.split()和.rsplit()**注意拼写！！！
        - .split()以括号中参数为界分割字符串，参数本身并不包括进去；
        - .split(“参数，可以为空字符”，分割次数)，分割次数默认是-1，表示有分隔符就分割
    - 换行分割：
        - 因不同系统换行符不同，无法使用换行符为分隔符
        - 有.splitlines()直接分割不同行
    - 拼接：.join()方法
        - 语法：“介词，不同拼接内容中间插入的东西，可为空”.join([列表，元素逗号隔开])
        - **拼接大字符串用 join 而非 +**：字符串不可变，+ 每次新建中间对象是 O(N²)；join 先算总长、一次分配内存是 O(N)
        - 注意：join的参数是元组，若要将字符串拼接，应该.join((<字符串1><字符串2>))
9. 字符串的格式化输出
    - 将变量插入字符串中输出：见D2-对象模型&类型系统，f"{变量}"
    - 更一般：使用.format方法：
        - "{} {}".format(参数1，参数2)：依次顺序填入大括号中，参数可以使任何数据类型
            - format()括号中是一个元组，可以通过下标索引调整输出顺序：
                - "{1}{0}"。format（元素1，元素2）
                - 进一步，可以使用下标多次输出相同元素
                - 转义：使用{{}}输出大括号
    - 对齐（align）：向左、向右、对齐、填充 ，字符
        - 语法：{（位置索引/变量名）：（对齐方向符号）(宽度)}.format(被对齐的内容，可有多个)
        - 填充：{:（插入字符）（宽度）}.format(【只对数字有效】)
        - 符号：
        - {:+}{:-}.format()--加号是在正数前填+，负数填-；减号不在正数前填，只在负数前填-；{: },在正数前加空格，负数前加负号
        - {:,}和{:_ }，将逗号、下划线作为千分符（位数不足则不显示）
    - 限制输出数位：
        - {: .(小数点后显示数字位数)f}，{: .(小数点前后总共显示数字位数)g}+.format()
        - {: .（数字）}，限制的是字符串位数宽度
        - {: .（符号）}，规定输出形式：b-二进制，d-十进制， o-八进制， x-十六进制（C）
            - 新：c-将参数以unicode字符的形式输出；符号前加#号，显示输出前缀
