## 为什么要有自己的博客

作为智能科学专业的大一新生，我需要一个地方：

1. **沉淀学习笔记**——公开写作倒逼自己把知识讲清楚；
2. **记录折腾过程**——踩过的坑，写下来才是经验；
3. **展示成长轨迹**——四年后再回头看，这里就是证据链。

## 这个网站是怎么搭的

- **框架**：[Astro](https://astro.build/) + [Astro Theme Pure](https://github.com/cworld1/astro-theme-pure)（静态站点生成，速度快、免服务器）
- **部署**：Vercel（免费托管，`git push` 自动上线）
- **设计**：米色纸面 + 海报橙点缀，首页大字排版致敬瑞士海报风格
- **内容**：博客长文、随记碎片、音乐记录三个板块

## 接下来的计划

- 把 Python 学习过程整理成系列笔记
- 给网站逐步加上评论、统计等功能，每加一项就写一篇记录
- 保持每月至少一两篇的更新频率

日拱一卒，功不唐捐。第一篇，就到这里。
